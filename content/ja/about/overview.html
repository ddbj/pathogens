本サイトについて

このポータルは SIB (スイスバイオインフォマティクス研究所) がとりまとめる国際コンソーシアム Pathogen Data Network の一環として日本DNAデータバンク (DDBJ)が運営しています。 ウェブサイトはスウェーデンの SciLifeLab Data Centre が公開する情報を基礎に GitHub および Hugo を用いて作成し、本家同様に我々のプログラムも MITライセンスで公開しています。

これまでの経緯

2020年10月 COVID-19データポータル (COVID-19 Data Portal Japan) を国立情報学研究所の RCOS(オープンサイエンス基盤センター) が開始

2025年6月 DDBJが上記ポータルの運営を正式に引き継ぎ
