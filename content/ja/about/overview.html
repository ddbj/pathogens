本サイトについて

このポータルは SIB (スイスバイオインフォマティクス研究所) がとりまとめる国際コンソーシアム Pathogen Data Network の一環としてDNAデータバンク・ジャパン (DDBJ)が運営しています。 ウェブサイトはスウェーデンの SciLifeLab Data Centre, が公開する情報を基礎に GitHub および Hugo を用いて作成し、本家同様に我々のプログラムも MITライセンスで公開しています。

これまでの経緯

ポータルは国立情報学研究所の RCOS (オープンサイエンス基盤センター) が 2020年に開始した "COVID-19 Data Portal Japan" を引き継ぐ形で2025年に開始されました。
