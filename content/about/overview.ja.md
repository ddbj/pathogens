{{< paragraph title="本サイトについて">}}
このポータルは国際コンソーシアム [Pathogen Data Network](https://pathogendatanetwork.org/) の一環として日本DNAデータバンク (DDBJ)が運営しています。 ウェブサイトはスウェーデンの [SciLifeLab Data Centre](https://scilifelab.se/data/) が公開する情報を基礎に GitHub および Hugo を用いて作成し、MITライセンスで公開しています。
{{< /paragraph >}}

{{< paragraph title="これまでの経緯">}}
* 2020年10月 COVID-19データポータル (COVID-19 Data Portal Japan) を国立情報学研究所の [RCOS](https://rcos.nii.ac.jp/) (オープンサイエンス基盤センター) が開始
* 2025年06月 DDBJが上記ポータルの運営を正式に引き継ぎ

{{< /paragraph >}}
