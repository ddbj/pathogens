About the portal

This portal is a part of Pathogen Data Network, a global consortium coordinated by the SIB (Swiss Institute of Bioinformatics, and is operated by DNA Data Bank of Japan (DDBJ). The website is built using Hugo on GitHub based on the code of SciLifeLab Data Centre, and like the original, we make all our codes open source under the MIT license.

History

An original portal was launched by RCOS (Research Center for Open Science and Data Platform, National Institute of Informatics) as "COVID-19 Data Portal Japan" in 2020 in collaboration with other COVID-19 data portals. The current version started in 2025 as a DDBJ service.
